# billing-system-python
GUI-based billing system using Python and Tkinter
# Billing System (Python + Tkinter)

## Features
- GUI-based billing system
- Product categories (Medical, Grocery, Cold Drinks)
- Tax and discount calculation
- Date & time on bill
- Save bills as text files

## Technologies Used
- Python
- Tkinter

## How to Run
1. Install Python
2. Run:
   python billing_system.py
